# Blog Feature - Image Upload Guide

## Default Image

Place a default blog image named `default-blog.png` in this directory.

## Uploaded Images

Blog post featured images will be automatically saved to this directory with the naming pattern:

- `blog-[timestamp]-[random].jpg/png/webp`

## Image Requirements

- **Max Size**: 5MB
- **Allowed Formats**: JPG, PNG, WEBP, GIF
- **Recommended Dimensions**: 1200x600px (2:1 ratio)

## Example Images for Testing

You can use free stock photos from:

- Unsplash (https://unsplash.com)
- Pexels (https://pexels.com)
- Pixabay (https://pixabay.com)

Search for keywords like:

- "finance"
- "money"
- "investing"
